# HomeSystemsSlider

Виджет слайдера карточек систем на публичной главной странице. В каждой карточке — два круговых графика (бублика): доля органов системы от общего числа ОС и доля сертификатов системы от общего числа сертификатов.

## Назначение

- Показать список систем (СДС) в виде горизонтального слайдера с автопрокруткой.
- Для каждой системы отобразить два donut-графика:
  1. **Доля от общего количества ОС** — «данная СДС» vs «другие» (в штуках).
  2. **Доля от общего количества сертификатов** — «данная СДС» vs «другие» (в штуках).
- Легенда под каждым бубликом в формате «значение / total шт.» (единица по умолчанию — «шт.»).

## API и данные

- **Endpoint:** `GET /public/get-systems-list` с параметрами `page=1`, `perPage=100`.
- **Ответ:** Laravel-пагинатор по сущности `ISystem`. В `meta` ожидаются:
  - `total_organs` — общее количество органов по всем системам;
  - `total_documents` — общее количество сертификатов по всем системам.
- Каждый элемент `data` — система с полями в т.ч. `system_name`, `organs_count`, `documents_count`, `gid`.

Данные кешируются на бэкенде (например, `SystemsTotalsService` с TTL). На фронте используется `useQuery` с ключом `["home-systems-slider"]` и `placeholderData: keepPreviousData`.

## Структура виджета

- **HomeSystemsSlider.tsx** — основной компонент: запрос данных, Swiper, карточки с двумя `PieChart` и легендами.
- **PieLegendWithTotal.tsx** — легенда к бублику: список пунктов «цвет + label: value / total unit» (по умолчанию unit = `"шт."`).
- **HomeSliderNavigation.tsx** — обёртка с кнопками «назад» / «вперёд» для слайдера.
- **HomeSystemsSlider.module.css** — стили: высота карточки (`.cardRoot` 250px), ширина слайда (`.slide` 440px), прелоадер и навигация (`min-height: 234px`), обрезка заголовка (`.titleClamp`).
